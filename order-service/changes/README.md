# Approved Change Records

Use `CHANGE-XXX-short-description.md` for approved changes affecting behavior, FRs/NFRs, architecture, ownership, contracts, diagrams, tests, sprint scope, deployment, or technology.

Each record must contain the request, reason, Project D1 references, affected requirements/services/contracts/diagrams/tests, result, verification, and reversal considerations. Update `docs/change-log.md` and reference the change ID in the related commit.

Do not create records for speculative/rejected ideas or typo-only edits.
